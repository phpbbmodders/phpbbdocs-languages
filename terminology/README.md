# Translator reference: terminology audits and glossaries

Per-language translation-quality writeups: terminology audits (does the
translation quote phpBB's real UI strings correctly?), human-review
notes for a native speaker, and supplementary glossaries for terms with
no confirmed match yet. Each language's own `README.md` indexes its
detailed files.

- [German (de_x_sie)](de_x_sie/README.md)
- [German (de)](de/README.md)
- [French (fr)](fr/README.md)
- [Danish (da)](da/README.md)
- [Italian (it)](it/README.md)

A language with no writeup yet (currently English) has no entry here.
Add a new language's directory to this list as soon as it gets its
first detailed writeup. See `phpbbdocs-hugo`'s
`docs/translation-process-prompt.md` for the audit process itself.
